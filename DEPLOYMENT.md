# Wasatch Industrial Hygiene & Safety Website Deployment

## Vercel Deployment

1. Import this GitHub repository into Vercel.
2. Select the Next.js framework preset.
3. Use the default build settings.
4. Deploy.

## Domain Configuration

After deployment, connect:

- wasatchsafetyih.com
- www.wasatchsafetyih.com

DNS records should be configured through the current domain provider.
